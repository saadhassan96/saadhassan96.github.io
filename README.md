# saadh.info

Personal academic website of Saad Hassan.

- Live site: https://saadh.info
- Archived site (2023 to September 2026): https://saadh.info/archive/
- Lab website: https://saadhassan96.github.io/a11y/

## Run locally

The site is plain HTML with no build step. Open `index.html` in a browser, or
serve the folder so paths behave as they do online:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.

Pushing to `main` publishes the site with GitHub Pages.
